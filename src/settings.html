Media keys

Leave this off on Wayland and on GNOME/KDE: the desktop already routes media keys through MPRIS. Turn it on only if media keys do nothing (typically bare X11 setups). Enabling both can make each keypress register twice.

Companion app server

The companion app must send this token when it connects. Choosing All interfaces lets any device on your network control playback and read the current track, so only do that on a network you trust.
